# Exploratory Data Analysis (EDA) Project

## Objective
Analyze a sales dataset to discover patterns, trends, and relationships using statistical summaries and visualizations.

## Technologies Used
- Python
- Pandas
- Matplotlib

## Files
- sales_data.csv
- eda_analysis.py
- sales_by_category.png

## Analysis Performed
- Loaded and explored the dataset
- Generated statistical summary
- Calculated category-wise sales
- Identified correlation between Sales and Profit
- Created a bar chart for sales by category

## Conclusion
The project demonstrates how Exploratory Data Analysis (EDA) helps understand data, identify trends, and support decision-making using visualizations.
